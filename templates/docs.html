Anime108 HLS Proxy API

API สำหรับค้นหา อ่านรายการตอน และสร้าง HLS proxy session โดยไม่มีระบบดาวน์โหลดหรือบันทึกวิดีโอลงดิสก์

GET/search?q={keyword}

ค้นหาอนิเมะ

GET /search?q=mushen

POST/api/parse

อ่าน metadata และรายการตอน

Content-Type: application/json

{"url":"https://www.anime108.com/mushen-ji/"}

POST/api/stream

resolve stream และสร้าง proxy session ชั่วคราว ค่า lang รองรับ Sound Track และ Thai

POST /api/stream
Content-Type: application/json

{
  "url": "https://www.anime108.com/mushen-ji-ep-2/",
  "lang": "Sound Track"
}

Response:

{
  "playlist_url": "/hls/8f2c1a9e4b7d6350/playlist.m3u8",
  "qualities": [
    {"label": "1080p", "path": "/hls/8f2c1a9e4b7d6350/1080p/index.m3u8", "resolution": "1920x1080"},
    {"label": "720p",  "path": "/hls/8f2c1a9e4b7d6350/720p/index.m3u8",  "resolution": "1280x720"}
  ],
  "session_id": "8f2c1a9e4b7d6350",
  "title": "Mushen Ji",
  "episode": 2,
  "lang": "Sound Track",
  "expires_in": 7200
}

GET/hls/{id}/{ความชัด}/index.m3u8

เลือกความชัดได้เอง ใช้ค่า label จาก qualities

GET /hls/{id}/1080p/index.m3u8   # ล็อกที่ 1080p
GET /hls/{id}/720p/index.m3u8    # ล็อกที่ 720p
GET /hls/{id}/auto/index.m3u8    # master playlist (ปรับอัตโนมัติ)
GET /hls/{id}/qualities.json     # รายการความชัด

playlist_url เป็น master playlist ที่รวมทุกความชัด จึงปรับอัตโนมัติได้ · 404 เมื่อไม่มีความชัดนั้น

GET/hls/{id}/{file}

ทุก resource ของ session อยู่ใต้ /hls/{id}/ และมีนามสกุลไฟล์จริง ทำให้ player, CDN และ Content-Type ทำงานถูกต้อง Server จะ rewrite URI ภายใน playlist ให้เป็นชื่อไฟล์ relative ของ session เดียวกันอัตโนมัติ

GET /hls/{id}/playlist.m3u8   # master playlist (ทุกความชัด)
GET /hls/{id}/index-1.m3u8    # media playlist ของแต่ละ variant
GET /hls/{id}/segment-12.ts   # video segment
GET /hls/{id}/key-3.key       # AES-128 key
GET /hls/{id}/init-2.mp4      # fMP4 init section
Range: bytes=0-1048575

รองรับ Range request (ตอบ 206 พร้อม Content-Range), HEAD, CORS preflight OPTIONS และ live playlist ที่ reload แล้วชื่อไฟล์คงเดิม

404 ไม่พบ resource ใน session · 405 method ไม่รองรับ · 410 session หมดอายุ · 502 upstream ผิดพลาด

<video> / hls.js → /hls/{id}/playlist.m3u8 → upstream HLS

Error response

ทุก endpoint ตอบ error ในรูปแบบเดียวกัน

{"error": "HLS session expired or was not found"}
