Anime108 HLS Proxy API

API สำหรับค้นหา อ่านรายการตอน และสร้าง HLS proxy session โดยไม่มีระบบดาวน์โหลดหรือบันทึกวิดีโอลงดิสก์

GET/search?q={keyword}

ค้นหาอนิเมะ

GET /search?q=mushen

POST/api/parse

อ่าน metadata และรายการตอน

Content-Type: application/json

{"url":"https://www.anime108.com/mushen-ji/"}

POST/api/stream

resolve stream และสร้าง proxy session ชั่วคราว ค่า lang รองรับ Sound Track และ Thai

POST /api/stream
Content-Type: application/json

{
  "url": "https://www.anime108.com/mushen-ji-ep-2/",
  "lang": "Sound Track"
}

Response:

{
  "playlist_url": "/hls/temporary-token/master.m3u8",
  "title": "Mushen Ji",
  "episode": 2,
  "lang": "Sound Track",
  "expires_in": 7200
}

GET/hls/{id}/master.m3u8

ส่ง master playlist ที่มีทุกความชัดเพื่อให้ HLS player เลือกแบบ adaptive bitrate โดย URI ของแต่ละความชัดจะถูก rewrite เป็น path ที่อ่านง่าย

/hls/{id}/720p/index.m3u8
/hls/{id}/1080p/index.m3u8

Segment, encryption key และ HLS resource อื่นจะผ่าน opaque token /hls/{token} โดยอัตโนมัติ และ session หมดอายุภายในเวลาที่กำหนด
