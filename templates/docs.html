Anime108 HLS Proxy API

API สำหรับค้นหา อ่านรายการตอน และสร้าง HLS proxy session โดยไม่มีระบบดาวน์โหลดหรือบันทึกวิดีโอลงดิสก์

GET/search?q={keyword}

ค้นหาอนิเมะ

GET /search?q=mushen

POST/api/parse

อ่าน metadata และรายการตอน

Content-Type: application/json

{"url":"https://www.anime108.com/mushen-ji/"}

POST/api/stream

resolve stream และสร้าง proxy session ชั่วคราว ค่า lang รองรับ Sound Track และ Thai

POST /api/stream
Content-Type: application/json

{
  "url": "https://www.anime108.com/mushen-ji-ep-2/",
  "lang": "Sound Track"
}

Response:

{
  "playlist_url": "/hls/temporary-token",
  "title": "Mushen Ji",
  "episode": 2,
  "lang": "Sound Track",
  "expires_in": 7200
}

GET/hls/{token}

ส่ง playlist, segment, encryption key และ HLS resource อื่นแบบ streaming โดย server จะ rewrite URI ภายใน playlist ให้ผ่าน proxy อัตโนมัติ Token ไม่เปิดเผย upstream URL และหมดอายุภายในเวลาที่กำหนด

<video> / hls.js → /hls/{token} → upstream HLS
